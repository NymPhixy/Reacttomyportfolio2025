## 🎨 Design System Reference

### Colors

```
Primary Gradient:   from-purple-600 to-purple-700
Accent Gradient:    from-pink-500 to-pink-600
Category Tags:      Blue (UX) | Purple (Frontend) | Pink (Concept)
Text Primary:       text-white
Text Secondary:     text-gray-300
```

### Spacing

```
Component Gap:      gap-6 sm:gap-8
Section Padding:    py-16 sm:py-24
Card Padding:       p-6 sm:p-8
Border Radius:      rounded-2xl (cards), rounded-lg (buttons)
```

### Typography

```
H1: 56-72px (Hero title)
H2: 48px (Section title)
H3: 32px (Subsection title)
H4: 20px (Card title)
Body: 16px (Main text)
```
